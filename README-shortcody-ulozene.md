# Uložené – ovládací prvky a shortcody

Použij viz `docs/CHANGELOG-beta9.3.md` a `AR_Community_beta9.3_nasazeni.md`.

`[ar_community_favorite_button]` (detail produktu), `[ar_community_favorite_products]` (výpis oblíbených), `[ar_community_saved_icon]` (Elementor menu), `[ar_community_saved]` (přehled), `[ar_community_saved_posts]` (samotné uložené články/příspěvky).


**Beta 9.4:** srdíčko je ikona. Na Woo detail/Single Product v Elementor Shortcode widgetu použij `[ar_community_favorite_button]` bez product_id. `product_id="123"` je jen pro statickou vazbu na konkrétní produkt. Volitelný text: `[ar_community_favorite_button label="1"]`. Do HTML menu v Elementoru není možné vložit shortcode přímo: použij hotový obsah `AR_Header_menu_ulozene_9.4.txt` s odkazem `/ulozene/` a ikonou; pro Shortcode widget platí `[ar_community_saved_icon]`.
