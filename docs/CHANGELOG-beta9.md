# Adrenaline Live 2.0 – beta.9.0 (wall layout)

- Feed cards: uncropped responsive media edge-to-edge across widths.
- Shop: horizontally scrollable recommendation strip of up to 20 visible and in-stock WooCommerce items, last card to shop, guest fallback.
- Subtle chip filters, added filter caption.
- Desktop two-column 70:30 sidebar (profile, sport relation, interests, friends, latest notices).
- YouTube auto-play: muted and at most one active iframe; only if the clip overlaps the top half of viewport, others destroyed on scroll/tab hiding. Browsers can block autoplay; click fallback remains.
- Existing chronological feed, incremental pagination, page template and floating app navigation left intact.
- Sport relation can be edited in existing community profile. No schema/DB migration required.
- Deployment: back up files, update plugin ZIP, regenerate caches, test anonymous and signed-in mobile/tablet/desktop.
