# AR Community 0.2.0-beta.9.7

- API `/me` nyní vrací uložené `sport_relation`, `sport_profession`, `sport_experience`, `avatar` a marketing opt-in. Žádná migrace dat.
- Moje komunita: dva jasné sloupce na desktopu (profil + Premium vlevo, přátelé + produkty/balíčky + uložené posty vpravo); mobil: profil, přátelé, Premium, produkty, články.
- Přátelé v účtu: přepínání Vyhledat / Pozvat / Moji přátelé; e-mailové pozvánky i sdílení WhatsApp používají stávající backend a Fresh Affiliate.
- Profilové foto: galerie či kamera telefonu, náhled, zmenšení před odesláním na 2 MB, zachování souhlasu s veřejnou URL.
- Premium: název ADRENALINE LIVE Premium.
- Produkty: společný formát ceny pro variable/simple a všechny REST výpisy; odstranění duplicitní screen-reader ceny.
- Slider: srdíčka na produkty používají stávající Favorites mechanismus včetně návštěvníků bez přihlášení.
- Uložené: oblíbené produkty a poté uložené články/příspěvky na jedné stránce, bez záložek; obrázky bez ořezu.
- Elementor Hero, horní menu, plovoucí spodní menu, databáze, objednávky a Fresh Affiliate zůstávají nedotčeny.
